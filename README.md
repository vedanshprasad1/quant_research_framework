# Quantitative Trading Research Platform

## Overview
This project is a research platform designed to investigate whether machine learning models can be used to develop profitable trading strategies.

The user is able to select a stock using its ticker symbol, then select financial features of the stock to feed into one or multiple machine learning models. They can then see information about the stock, then train and backtest the models, evaluating performance relative to random buying and buy-and-hold. Other analysis can be carried out, such as t-test analysis, and Pearson correlation and feature importance analyses. They can also compare experiments with other previously run experiments, and also use the models to predict how a stock will move the next trading day.

## Features

### Stock selection
- The user can select a stock using its ticker symbol
- The user can specify the date range used for an experiment

### Feature selection
- The user can select a range of financial features for the machine learning models to use
- Feature configurations such as moving average and volatility windows can be adjusted

### Machine Learning model selection
- The platform supports eight models; four classifiers and four regressors
- The user can choose which models to run during an experiment

### Stock analysis
- Graphs can be displayed showing the stock's value, returns, moving averages, volatility, and feature distributions

### Backtesting
- Models can be used to generate trading strategies based on their predictions
- Strategies can be compared against buy-and-hold and random buying

### Evaluation
- Model performance can be evaluated using metrics such as accuracy, precision, recall, F1 score, MAE, RMSE and R²
- Trading strategies can be evaluated using profit, Sharpe ratio, and maximum drawdown

### Statistical analysis
- T-tests can be used to compare future returns between observations with different feature values
- Pearson correlation coefficients can be calculated between features and returns
- Feature importance analysis can be used to investigate which features contributed most to model predictions

### Experiment comparison
- Results from previously run experiments can be compared
- Model and backtesting results can be viewed in tables

### Future prediction
- The user is able to select a date and all models in the experiment will be run to predict how the stock will move on this day
- Classification models predict the direction of the stock, while regression models predict its return

## Financial Features

The platform supports the following financial features:

- Percentage return
- Log return
- Simple moving average (SMA)
- Price-to-moving-average ratio (PMAR)
- Rolling volatility
- Momentum
- Volume
- Exponential moving average (EMA)
- Moving average difference
- Relative Strength Index (RSI)
- Relative daily price range
- Bollinger Band position

## Backtesting

The platform tests trading strategies using the predictions generated by the machine learning models.

The available strategies are:

- Simple Buying
- Buy and Hold
- Random Buying
- Confidence Buying for classification models
- Threshold Buying for regression models

Each strategy records its final capital, profit and number of trades. The platform also calculates the Sharpe ratio and maximum drawdown and can display the capital history of each strategy.

## Statistical Analysis

The platform provides several methods for analysing financial features, returns and model predictions.

### T-Test Analysis

Welch's independent two-sample t-test is used to compare future returns for observations above and below the median of a selected feature.

### Pearson Correlation

Pearson correlation coefficients are calculated to measure the linear relationship between financial features and returns.

### Feature Importance

Feature importance analysis is used to investigate which financial features contribute most to the predictions of the machine learning models. Different methods are used depending on the model, including model coefficients, built-in feature importance and permutation importance.

## Experiment Management

Experiments can be created with different stocks, date ranges, financial features, models and model configurations.

Experiment results are stored so that they can be viewed again or compared with other experiments.

Results can also be exported to CSV files for further analysis.

## Future Prediction

After training the models, the platform can be used to predict the movement of a stock on a selected future trading day.

The program downloads the latest available data before the selected date, calculates the required financial features and passes them to the trained models.

Classification models predict whether the stock will move up or down, while regression models predict the expected return.

## Installation

Clone the repository and navigate into the project directory.

Install the required Python packages using:

```bash
pip install -r requirements.txt
```

The project can then be run using:

```bash
python main.py
```

From there, follow the prompts in the terminal to create and run an experiment

## Project Structure

The project is organised into separate modules for data processing, feature engineering, machine learning, model analysis, backtesting, statistical analysis and visualisation.

## Results

The platform stores the results of each experiment, including model performance and backtesting results.

Model results include metrics such as accuracy, precision, recall, F1 score, MAE, RMSE, R² and directional accuracy.

Backtesting results include profit, final capital, number of trades, Sharpe ratio and maximum drawdown.

Results can be viewed in the terminal and exported to CSV files.

## Limitations

- The project uses historical stock data, so good historical performance does not guarantee future performance
- Backtesting does not account for transaction costs, slippage or other real-world trading costs
- The models are tested on individual stocks and results may not generalise to other stocks or market conditions
- Random buying results can vary between experiments
- The project is intended as a research and learning project rather than a system for making real trading decisions
